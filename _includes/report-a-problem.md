## Report a Problem

- **A bug or an idea:** [the forms]({{ site.report_url }})
  (needs a GitHub account). *Help > Report a Problem* in the app opens them.
- **No GitHub account:** email [qa@mncardboard.com](mailto:qa@mncardboard.com)
  and I'll put it in the forms for you.
- **Something private** (your collection, a purchase, an account):
  [{{ site.email }}](mailto:{{ site.email }}). It won't be posted.
- **A security problem:** [how to tell me privately](https://github.com/{{ site.github_username }}/MinnesotaCardboard-Site/blob/main/SECURITY.md),
  never a public issue.

I maintain mncb by **myself**. Most emails get an answer *within a few days*.
