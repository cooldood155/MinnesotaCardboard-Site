# Getting Help

Everything's on [mncardboard.com/help](https://mncardboard.com/help/):
getting started, every page of the app, questions, fixing problems and
testing.

## Still stuck

- **A bug or an idea:** [the forms](https://github.com/cooldood155/MinnesotaCardboard-Site/issues/new/choose).
  *Help > Report a Problem* in the app opens them.
- **No GitHub account:** email [qa@mncardboard.com](mailto:qa@mncardboard.com)
  and I'll put it in the forms for you.
- **Something private** (your collection, a purchase, an account):
  [evanreumann@mncardboard.com](mailto:evanreumann@mncardboard.com). It won't
  be posted.
- **A security problem:** [`SECURITY.md`](SECURITY.md), never a public issue.

I maintain mncb by **myself**. Most emails get an answer *within a few days*.
