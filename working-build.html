Working build or test build?

Test build

  • Made when a new version is ready (like 0.1.2)
  • Has a news post saying what's in it
  • Changes less often
Get the test build

Working build (this page)

  • Made every time the code changes (and passes its tests)
  • Has new things before they're in a test build
  • Can have bugs a test build wouldn't

Before you try it

  • Nothing gets installed. It keeps its own collection and settings, so nothing you already have gets touched.
  • Don't keep your real collection in it. It stops working {{ build.days | default: 30 }} days after it's built, and the next one might not open what this one saved.
  • Found something wrong, or have an idea? Tell me here, or email qa@mncardboard.com. Say it was the working build{% if build.commit %} (code {{ build.commit }}){% endif %}, so I know which one. What's being fixed next is on the project board.
