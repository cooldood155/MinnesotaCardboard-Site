The site got cleaned up:

- **Faster:** no theme or plugins anymore, just the site's own pages and
  styles, and every picture is smaller. Less to download on every page.
- **A Features page:** everything mncb does (and is going to do), in one
  place.
- **Search and shared links:** every page has its own title and description.
- **A safer admin sign-in:** the admin page only asks GitHub for what it
  needs (public repos, never private ones), its sign-in window only runs its
  own script and can't be put inside another site, and the editor's script is
  checked before it runs.
