## Still stuck

- **A bug or an idea:** [the forms](https://github.com/cooldood155/MinnesotaCardboard-Site/issues/new/choose)
  (needs a GitHub account). *Help > Report a Problem* in the app opens them.
- **No GitHub account:** email [qa@mncardboard.com](mailto:qa@mncardboard.com)
  and I'll put it in the forms for you.
- **Something private** (your collection, a purchase, an account):
  [evanreumann@mncardboard.com](mailto:evanreumann@mncardboard.com). It won't
  be posted.
- **A security problem:** [how to tell me privately](https://github.com/cooldood155/MinnesotaCardboard-Site/blob/main/SECURITY.md),
  never a public issue.

I make mncb by **myself**. Most emails get an answer *within a few days*.
